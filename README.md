# ⚡ Rohit's Developer Portfolio

A modern, high-performance, cyber-glassmorphic personal portfolio website engineered for **Rohit** (B.Tech, Motilal Nehru National Institute of Technology Allahabad).

Designed to showcase full-stack engineering expertise, real-time WebSocket systems, deep learning projects, and algorithmic problem-solving to technical recruiters and collaborators.

---

## 🌟 Key Highlights & Features

- **Interactive Developer CLI Terminal (`#terminal`)**:
  - Live command-line terminal emulator with auto-completion (`Tab`), command history (`↑` / `↓`), and sound feedback.
  - Commands: `help`, `about`, `skills`, `projects`, `education`, `contact`, `resume`, `theme`, `matrix`, `sudo hire rohit`, `clear`.
  - Easter eggs including digital green rain matrix mode and an executive recruiter fast-track prompt.
- **Dynamic Particle Constellation Canvas**:
  - Interactive canvas background responding dynamically to mouse movements, window resizing, and theme mode.
- **Showcase of Real Projects**:
  - **MarketMind**: Stock price prediction using LSTM neural networks (TensorFlow/Keras) with Streamlit analytics.
  - **Prescripto**: Full-stack doctor appointment & hospital management suite with Stripe/Razorpay and Cloudinary.
  - **Chatify**: Real-time messaging platform with WebSockets (Socket.io) and Zustand.
  - **Sorting Visualizer**: Interactive algorithm comparison suite for Merge, Quick, Bubble, and Heap Sort.
  - **E-Commerce & REST API Dashboards**: Asynchronous data tools.
- **Interactive Project Deep Dive Modal**:
  - Detailed system architecture breakdowns, engineering highlights, and repository links.
- **Integrated Printable Resume Modal**:
  - Clean recruiter-ready resume view with one-click print to PDF.
- **Dark & Light Mode**:
  - Persistent theme switcher with custom CSS variables and glassmorphism styling.
- **Contact & Direct Clipboard Utility**:
  - Instant one-click copy for institutional email (`rohit.20224124@mnnit.ac.in`) with toast notifications and contact form dispatch.
- **Responsive & Accessible**:
  - Mobile-friendly drawer navigation, smooth scrolling, and accessible semantic markup.

## 🚀 Quick Start / How to Run

### Method 1: Direct Browser Launch (No installation required)
Simply double-click `index.html` in your file explorer, or right-click `index.html` and select **Open with Chrome / Edge / Firefox**.

### Method 2: Local Web Server
You can run any local static web server:

```bash
# Using Node / npx (Zero install)
npx serve .

# Or using Python 3
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 1-Click Deployment Guide

### Deploy to GitHub Pages:
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   ```
2. Create a repository named `portfolio` on GitHub.
3. Link and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Rohit8825/portfolio.git
   git push -u origin main
   ```
4. Go to **Settings > Pages** on your GitHub repo and select the `main` branch to go live instantly!

### Deploy to Vercel / Netlify:
- Simply drag and drop the `protfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com). No build command needed!
